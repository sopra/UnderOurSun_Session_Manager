# UnderOurSun Session Manager

ボードゲームのシナリオをカード形式で逐次表示するWebアプリケーション。

## 概要

物理的なボードゲームを進行しながら、アプリ上でストーリーカードを1枚ずつ表示し、セッションを管理できます。

## 技術スタック

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **ローカルストレージ** (データ永続化)

## 主な機能

### セッション管理
- **作成・編集・削除**: 複数のシナリオを作成・編集・削除
- **一覧表示**: 保存されたセッションを一覧で管理
- **進行状況保存**: 現在のカード位置を自動保存

### カード表示機能
- **逐次表示**: セットアップ、ストーリー、イベントカードを1枚ずつ表示
- **ナビゲーション**: 次へ・前へ・最初からの移動が可能
- **セットアップカード**: 専用フォーマットで詳細情報を表示

### カード編集機能
- **完全編集**: すべてのカードフィールドを編集可能
- **カード追加・削除**: セッション内でカードを自由に追加・削除
- **動的配列**: コンポーネントやセットアップ手順を動的に追加・削除
- **カードナビゲーション**: タブとボタンで複数カード間を移動

### その他
- **レスポンシブデザイン**: モバイル・タブレット・デスクトップ対応
- **ローカルストレージ**: データの永続化

## 開発環境のセットアップ

### 必要な環境

- Node.js 20以上
- npm 9以上

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build

# 本番環境での起動
npm start
```

## 開発サーバー

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてアプリケーションを確認できます。

## データモデル

### Session
- セッションのメタデータと進行状況を管理
- カードの配列を保持

### Card
- カードのタイプ（setup, story, event）
- コンテンツ（タイトル、ストーリー、条件など）

## 使い方

### セッション作成
1. トップページまたはセッション一覧から「新規作成」をクリック
2. タイトルと説明を入力
3. サンプルカードが自動的に追加されます

### セッション編集
1. セッション一覧で「編集」ボタンをクリック
2. タイトルと説明を編集
3. 「保存」をクリック

### カード編集
1. セッション一覧で「カード編集」ボタンをクリック
2. 各カードのフィールドを編集
   - タイトル、ストーリー
   - セットアップカードの場合: コンポーネント、手順、クリア/ゲームオーバー条件
   - 次のカードを引く条件
3. 「+ コンポーネントを追加」「+ 手順を追加」で動的に項目を追加
4. 「カードを追加」で新しいカードを追加
5. 「カードを削除」で不要なカードを削除
6. 「保存する」で変更を保存

### カードプレイ
1. セッション一覧で「続きから開始」をクリック
2. カードを読みながらゲームを進行
3. 条件を満たしたら「次のカードを引く」をクリック
4. 前のカードに戻ることも可能
5. 「最初から」で最初のカードに戻る
