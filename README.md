# UnderOurSun Session Manager

ボードゲームのシナリオをカード形式で逐次表示するWebアプリケーション。

## 概要

物理的なボードゲームを進行しながら、アプリ上でストーリーカードを1枚ずつ表示し、セッションを管理できます。

## 技術スタック

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **ローカルストレージ** (データ永続化)

## 主な機能

- **セッション管理**: 複数のシナリオを作成・保存・削除
- **カード表示**: セットアップ、ストーリー、イベントカードを逐次表示
- **進行状況保存**: 現在のカード位置を自動保存
- **レスポンシブデザイン**: モバイル・タブレット・デスクトップ対応

## 開発環境のセットアップ

### 必要な環境

- Node.js 20以上
- npm 9以上

### インストール

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build

# 本番環境での起動
npm start
```

## 開発サーバー

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてアプリケーションを確認できます。

## データモデル

### Session
- セッションのメタデータと進行状況を管理
- カードの配列を保持

### Card
- カードのタイプ（setup, story, event）
- コンテンツ（タイトル、ストーリー、条件など）

## 使い方

1. **セッション作成**: トップページまたはセッション一覧から「新規作成」
2. **カード表示**: セッションを選択してカードを表示
3. **進行**: 「次のカードを引く」ボタンで次のカードへ
4. **管理**: セッション一覧からセッションの削除や再開が可能
